# Preparação das imagens do tutorial DJI

Ferramenta: edição de imagem integrada (`image_gen`). As imagens foram revisadas visualmente após a edição. As capturas JPEG originais foram preservadas; o README exibe as versões PNG anotadas.

## Instruções de edição utilizadas

Instrução comum: editar as capturas reais para um tutorial, preservar os textos, ícones, valores e disposição dos controles; remover completamente a cena filmada pela câmera e as margens externas; adicionar contornos vermelhos sem cobrir as informações. Não criar novos controles nem alterar a configuração apresentada.

1. **Menu:** isolar o detalhe do botão de três pontos no canto superior direito, remover as demais informações e a imagem da câmera, ampliar e desenhar um círculo vermelho ao redor do botão.
2. **Transmissão:** manter apenas o painel direito; circular a aba “Transmissão” e a linha “Plataformas de transmissão ao vivo”.
3. **RTMP:** manter apenas o painel direito; circular o ícone e o nome “RTMP”.
4. **Configuração:** manter apenas o painel direito; circular o campo com `rtmp://192.168.15.2:1935/drone` e o botão “Iniciar transmissão ao vivo”. Preservar as opções de resolução e taxa de bits visíveis.

Os contornos indicam o local de acesso; o IP é um exemplo e deve ser substituído pelo endereço real exibido pelo servidor.
