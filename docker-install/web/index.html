Sobre o projeto

◈

Drone Streaming Server

Servidor de vídeo para receber uma publicação RTMP de um dispositivo compatível com RTMP e distribuí-la na rede local por WebRTC e HLS.

DockerMediaMTXWebRTCHLS

Projeto independente, sem afiliação com a DJI. A compatibilidade depende do drone, do controle e da versão do aplicativo.
