Reprodução

O IP do computador que executa o servidor, acessível pela sua rede.

Preferências salvas apenas neste navegador. Alterar o IP aqui não altera o endereço anunciado pelo servidor. Para mudar a rede do servidor, reinicie pelo install-DroneStreamingServer.sh com o IP correto.

Drone Streaming Server

Um servidor local para receber o vídeo do seu drone por RTMP e acompanhar a transmissão por WebRTC ou HLS.

DockerMediaMTXWebRTCHLS

Projeto independente, sem afiliação com fabricantes de drones. A compatibilidade depende do equipamento e do aplicativo utilizados.
